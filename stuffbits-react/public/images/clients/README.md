# Client Logos

To use your real client logos:

1. Add logo images here (1.png, 2.png, 3.png, etc.)
2. Add UrjaNxt logo as `urjanxt.png` (if not using Clearbit)
3. Update company names in `ClientsTrusted.jsx` to match logo order

Or copy from the old site:
```
cp ../../assets/img/clients/*.png ./
```

Logos should be PNG with transparent background, ideally 200x80px or similar.
